# FoodSharing

## Purpose
FoodSharing is a platform designed to connect individuals looking to share surplus food with those who need it. This initiative aims to reduce food waste and foster a community-oriented sharing culture.

## Live URL
- [FoodSharing on Firebase](https://foodsharing-49ddc.web.app/)
- [FoodSharing on Vercel](https://food-sharing-eight.vercel.app/)

## Key Features
1. **User Authentication**: Secure login and registration system integrated with Firebase Authentication.
2. **Food Listing**: Users can post, view, and manage surplus food listings.
3. **Interactive Map**: Locate nearby food-sharing opportunities with integrated geolocation features.
4. **Real-Time Updates**: Stay updated with real-time notifications using Firebase and react-hot-toast.
5. **Responsive Design**: Fully responsive interface ensuring optimal user experience across all devices.
